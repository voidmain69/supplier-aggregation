# ADR-0008: Дельта-синхронізація через watermark конектора

**Статус:** прийнято · 2026-07-12

## Контекст

Повний обхід каталогу постачальника дорогий (тисячі запитів, ліміт Brain — 3 rps/акаунт) і не годиться для
частих оновлень. ТЗ §7.1 вимагає дельт кожні 10–15 хв. Brain дає `modified_products` — ідентифікатори
змінених з певного часу. Питання: **хто володіє "часом останнього синку"** і як не втратити зміни.

## Рішення

- Подія `sync.job.requested` отримує опційне `mode` (`full` | `delta`; відсутність = full — backward-compatible).
  Оркестратор задає режим per-account у розкладі (часта дельта-каденція + рідший full re-baseline).
- **Watermark належить конектору** (таблиця `sync_watermark` per supplier+account у БД connector-brain) —
  бо «що змінилось з X» специфічне для постачальника. Оркестратор лише вирішує full/delta.
- Дельта: читає watermark → `fetch_deltas(since)` (сторінки `modified_products`) → по кожному id тягне
  продукт+офер → re-stage через **ті самі ідемпотентні** `sync_products`/`sync_offers`. Без watermark
  (перший синк) — прозорий фолбек на full.
- Watermark просувається до **часу початку** синку (не завершення): зміна, зроблена під час синку,
  перечитається наступного разу, а не загубиться.

## Альтернативи

- *Оркестратор передає `since` у події* — оркестратору довелося б знати семантику часу постачальника і
  зберігати стан per-connector; природніше в конекторі.
- *Watermark = час завершення синку* — вікно втрати змін під час довгого синку. Відкинуто на користь часу старту
  (ціна — можливе повторне оброблення, але воно ідемпотентне).
- *Стрім змін / webhooks від постачальника* — Brain не надає; polling `modified_products` — наявний примітив.

## Наслідки

- Дельти дешеві (тільки змінене), тож інтервал 10–15 хв реальний у межах ліміту 3 rps.
- Періодичний `full` потрібен як «re-baseline» (дельти можуть пропустити рідкісні події постачальника) —
  це окремий запис розкладу, не автоматика.
- Overlap-переоброблення на межі watermark безпечне завдяки ідемпотентності staging (content-hash / зміна ціни).
